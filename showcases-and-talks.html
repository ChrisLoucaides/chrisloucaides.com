UX: A Backend Perspective

A talk exploring how backend engineers can contribute meaningfully to user experience. Rather than treating UX as purely a frontend or design concern, this talk argues that decisions made deep in the stack — around API contracts, error handling, and data modelling — have a direct and often underappreciated impact on what users ultimately see and feel.
